# SÚPERCONSOLA

Un proyecto realizado en C# y .NET en el que incluye dos minijuegos:

- Ahorcado
- Viborita

Esta actividad fue desarrollada utilizando los conceptos vistos en la materia de Arquitectura de Software.

---
